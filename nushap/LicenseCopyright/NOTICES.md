## Notices

### Changes to the Software

This software is part of a larger symbolic AI toolkit that is being developed by researchers from ICREA/UdL. Requests for changes and/or bug reports can be communicated to the main architect/developer (JMS, jpms@icrea.cat). However, the software should not be modified in **any** way. Due to a lack of manpower, changes to the software will **not** be assessed or integrated.

### Distribution of the Software

No parts of this software should be distributed/circulated without explicit consent from the main architect/developer (JMS, jpms@icrea.cat). The toolkit development roadmap contemplates the public release of the software, but only when it is deemed sufficiently tested and validated by the main developer (JMS, jpms@icrea.cat).
